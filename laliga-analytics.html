Where the data comes from

Import any league file in the football-data.co.uk format (columns Date, HomeTeam, AwayTeam, FTHG, FTAG, HTHG, HTAG, HS, AS, HST, AST, HF, AF, HC, AC, HY, AY, HR, AR) — for example a newer La Liga season or the Premier League. The file stays in this browser.

This dataset has match-level data only: no player stats and no expected goals (xG).
